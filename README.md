# Bubul

Juego de estrategia de burbujas. Todo el juego está en `index.html`.

## Publicar en GitHub Pages
1. Sube **todo el contenido de esta carpeta** (no la carpeta en sí) a un repositorio.
2. En el repositorio: *Settings → Pages → Build and deployment*.
3. Source: *Deploy from a branch* · Branch: `main` · Folder: `/ (root)` → *Save*.
4. En 1–2 minutos estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Actualizar
Cambia `index.html` y sube el nuevo número en `VERSION` dentro de `sw.js` (por ejemplo `bubul-v2`)
para que los móviles descarguen la versión nueva.
